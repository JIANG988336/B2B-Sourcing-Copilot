# 外贸聊单专家 · B2B Sourcing Copilot

> A master prompt that turns any AI assistant into a B2B sourcing sales expert — deal coach, psychology analyst, and risk officer in one.

这不是一个代码项目，是一份**提示词工程作品**：为服务型外贸公司（对标 jingsourcing 的全品类采购服务模式）设计的 AI 分身提示词，约 1.5 万字，覆盖从询盘进线到成交交付的完整 0-1 流程。

## 它解决什么问题

外贸 B 端新手单人卖家的一天：不知道下一步该干什么、看不懂客户每句话背后的心理、英文回复写不动、怕被骗怕垫资怕货出问题。这份提示词把这三件事合并成一个角色——

| 身份 | 职责 |
|---|---|
| 顶尖销冠 | 分析客户心理、逐句生成高转化英文回复（附中文对照） |
| 私人教练 | 每次只给下一步最该做的一件事，说清为什么（0-1 阶段防多线程崩溃） |
| 风险控制官 | 每单先过七类风险清单，付款 / 验货 / 合规红线前置 |

## 核心设计：7 模式自动路由

粘贴任意一段话，AI 自动识别进入对应模式，无需手动选择：

| 识别信号 | 模式 |
|---|---|
| 提到难题 / 下一步 / 规划 | 模式一：难题指导（每次只给一件事） |
| 要求分析客户整体情况 | 模式二：痛点与心理分析（五阶段模型 + BANT + 人格读人术） |
| **直接粘贴客户原话（默认模式）** | 模式三：逐句回复教练（潜台词→策略→英文回复→中文对照→反应预判） |
| 提到转化 / 催单 / 推进 | 模式四：聊单转化（信任×需求×紧迫 诊断） |
| 提到 10 倍 / 增长机会 | 模式五：10x 增长雷达（内化《10x Is Easier Than 2x》） |
| 提到风险 / 靠不靠谱 | 模式六：风险预警（七类风险清单） |
| 提到流程 / 进度 / 从 0 开始 | 模式七：0-1 全流程陪跑（九阶段 SOP） |

## 内置的实战资产

- **双语话术库**：10 个高频场景 + 附录 7 组分档打法（失联三档跟进、价格异议三档、样品三步流程、付款方式风险对照表、临门促单工具、询盘筛选打分法、跨市场微调指南）
- **风控红线**：首单 30% 定金铁律、六种付款方式风险等级表、七类风险清单
- **诚信与数据纪律**：0 成交阶段不虚构案例、不冒充工厂、无数据不引用统计——每条话术都标注了"什么条件下才允许发送"
- **复盘进化机制**：每单沉淀战例条目，手动迭代回提示词

## 使用方法

1. 打开 [外贸聊单专家.md](./外贸聊单专家.md)，全文复制
2. 粘贴给任意 AI 助手（ChatGPT / Claude / 豆包 / 通义等）作为系统提示词或首条消息
3. 日常使用：把客户的话原样丢给它，其余自动路由

文件内所有【待填】处按自己的业务情况替换即可复用。
